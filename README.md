**Port do Remake de Resident Evil 1 do GameCube para PS2** 

Este projeto tem como objetivo portar Resident Evil (2002), originalmente lançado
no GameCube, para o PlayStation 2, preservando a experiência original. Não tenho
muita experiência em desenvolvimento de jogos ou programação ainda,
pois estou aprendendo. No entanto, sou apaixonado pela franquia Resident Evil.
Como Resident Evil 4 foi portado com sucesso do GameCube para o PS2, pensei que fazer
o mesmo com Resident Evil 1 talvez não fosse algo totalmente impossível.
Estou disposto a contribuir, aprender e ajudar da maneira que puder.
Espero sinceramente que este projeto tenha sucesso e, eventualmente,
resulte em uma ISO jogável no PS2.



**Resident Evil 1 Remake Port from GameCube to PS2**

This project aims to port Resident Evil (2002), originally released for the GameCube,
to the PlayStation 2 while preserving the original experience. I don't have much experience

to the PS2, I thought that doing the same with Resident Evil 1 might not be entirely impossible, 
I'm willing to contribute, learn, and help in any way I can.
I sincerely hope this project succeeds and eventually results in a playable PS2 ISO.
